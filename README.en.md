## Overview

This repository is an **AI application API backend** intended to run locally (on-premises), providing an LLM abstraction layer, RAG, and file/transcribe/image features.

It is an independent, unofficial derivative of [`digital-go-jp/genai-ai-api`](https://github.com/digital-go-jp/genai-ai-api), the generative AI platform "GENAI (源内)" published as OSS by Japan's Digital Agency. It is not affiliated with or endorsed by the Digital Agency or the upstream project. See [DISCLAIMER.md](DISCLAIMER.md).
